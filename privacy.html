PromptCard AI - Image to Prompt Privacy Policy

Effective date: July 29, 2026

PromptCard AI - Image to Prompt is a Chrome extension that converts images and user-selected screen regions into detailed AI prompts. This policy explains what data the extension handles and why.

Data we handle

  • Account information: email address and authentication tokens used to sign in and maintain a session.
  • Website content: images or screen regions explicitly selected by the user for analysis.
  • User configuration: language, model preferences, optional API endpoint and API key, and prompt history stored in Chrome extension storage.
  • Service and billing data: credit balance, transaction status, and operational request metadata needed to provide the service and prevent abuse.

How data is used

Selected visual content is sent only when the user starts an analysis. It is used to generate the requested prompt. Account and authentication data is used to provide sign-in, session access, integrated credits, prompt history, and billing status. Configuration and history are used to preserve user settings and results.

Google Sign-In

Google Sign-In is offered only as an authentication method for a PromptCard account. PromptCard receives the basic account identity needed to create and maintain the application session. Google Sign-In does not grant PromptCard access to Gmail, Google Drive, contacts, or unrelated Google data. Signing in does not start image analysis; images and screen regions are processed only after a separate, explicit user action.

Data sharing

Data may be processed by PromptCard's infrastructure and service providers necessary to provide authentication, AI analysis, and billing. If a user configures a third-party OpenAI-compatible API, selected visual content and the user's API credentials are sent to that provider at the user's direction. PromptCard does not sell user data or use it for advertising, creditworthiness, or unrelated purposes.

Storage and security

Preferences, optional API credentials, sessions, and prompt history may be stored locally through Chrome's extension storage. Data sent to PromptCard services is transmitted over HTTPS. We retain server-side data only as needed to operate, secure, and comply with legal obligations for the service.

User choices

Users control when an image or region is analyzed. Local extension data can be removed by signing out, clearing extension storage, or uninstalling PromptCard AI. Users may choose their own compatible API provider instead of the built-in service.

Limited use

PromptCard AI's use and transfer of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
