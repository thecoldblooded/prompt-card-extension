# PromptCard AI Chrome Web Store Description Design

## Objective

Replace the existing Chrome Web Store description with professional, detailed English copy that improves relevant search coverage and clearly explains the extension without keyword stuffing or unsupported claims.

## Approved Positioning

Lead with **Image to Prompt / AI Prompt Generator** for broad search relevance. Present creator workflows as secondary benefits for artists, designers, marketers, content creators, and prompt engineers.

## Copy Structure

1. Search-focused opening built around “image to prompt” and “AI prompt generator.”
2. Concise value statement explaining high-fidelity visual analysis.
3. Scannable feature list covering verified extension capabilities.
4. Three-step usage instructions.
5. Practical creator use cases.
6. Accurate built-in service, custom API, storage, and privacy notes.

## Accuracy Constraints

The listing may claim only capabilities verified in the extension:

- Analyze webpage images from the right-click context menu.
- Show an optional hover “Get Prompt” action.
- Capture and analyze a selected screen region.
- Generate structured prompt details for subject, style and medium, composition and angle, lighting and color, and supporting visual details.
- Offer a built-in account-based service using credits.
- Accept a user-configured OpenAI-compatible base URL, API key, and model.
- Provide popup and Chrome side-panel workflows.
- Keep account-scoped prompt history in Chrome extension storage.
- Support English, Turkish, German, French, and Spanish interfaces/output options.
- Send visual content for analysis only after a user initiates an analysis.
- State that PromptCard does not sell user data, consistent with the privacy policy.

The copy must not promise universal model compatibility, perfect reconstruction, guaranteed output quality, or processing that the product does not perform.

## Final Listing Description

PromptCard AI is an image-to-prompt and AI prompt generator Chrome extension that transforms images and selected screen regions into detailed, structured prompts for generative AI workflows.

Instead of describing a reference image manually, start an analysis directly from your browser. PromptCard examines the visible subject, visual style, medium, composition, camera angle, lighting, color palette, atmosphere, and supporting details. It then produces a high-fidelity visual prompt that is ready to copy, refine, and use in your preferred creative workflow.

KEY FEATURES

• Image to prompt: Right-click an image on a webpage and generate a detailed AI prompt.
• Screen-region capture: Select and analyze only the area that matters instead of processing the entire page.
• Optional hover action: Access “Get Prompt” directly from supported webpage images.
• Structured visual analysis: Review subject, style and medium, composition and angle, lighting and color, and important details in a clear format.
• Built-in AI service: Sign in and analyze images with account-based PromptCard credits—no external API setup is required to get started.
• Custom AI provider: Connect an OpenAI-compatible API using your own base URL, API key, and model.
• Prompt history: Review, copy, and reuse previous results stored for your account in Chrome extension storage.
• Flexible workspace: Open PromptCard from its compact popup or use the Chrome side panel while browsing.
• Multilingual experience: Use PromptCard in English, Turkish, German, French, or Spanish.

HOW IT WORKS

1. Right-click an image, use the optional hover action, or start screen-region selection from PromptCard.
2. Choose the visual content you want to analyze and initiate the request.
3. Review the generated visual prompt, copy it, and adapt it for your preferred AI image or creative tool.

BUILT FOR CREATIVE WORKFLOWS

PromptCard helps artists, designers, marketers, content creators, researchers, and prompt engineers move from visual reference to usable prompt faster. Use it to study composition, document an art direction, explore lighting and color choices, prepare creative briefs, or reduce repetitive prompt writing.

BUILT-IN CREDITS OR YOUR OWN API

Use the built-in PromptCard AI service with an account and available credits, or configure a compatible provider from the extension settings. Custom API mode lets you enter your provider’s base URL, API key, and model so you can use an OpenAI-compatible service that fits your workflow.

PRIVACY AND CONTROL

PromptCard sends selected visual content for analysis only when you initiate a request. Preferences, credentials, sessions, and prompt history may be stored in Chrome extension storage to provide the extension’s features. If you configure a third-party API, selected visual content and the required credentials are sent to that provider at your direction. PromptCard does not sell user data or use it for advertising.

Turn visual references into clear, reusable AI prompts without leaving your browser. Install PromptCard AI and make image-to-prompt analysis part of your creative workflow.

## Acceptance Criteria

- The final description is in English and remains below Chrome Web Store’s 16,000-character limit.
- The opening prioritizes “image to prompt” and “AI prompt generator.”
- Keywords read naturally and are not repeated solely for ranking.
- Every feature and privacy statement is supported by the current extension implementation or privacy policy.
- The description is saved in the Chrome Web Store listing and still appears after a page reload.
- The listing’s pending-review state is not withdrawn or changed without explicit user approval.
